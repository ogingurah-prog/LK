LEMBARKU - cara menaruh aplikasi di internet (gratis)

Isi folder ini adalah website lengkap. Cukup unggah SEMUA file ke salah satu layanan di bawah, lalu kamu dapat link yang bisa dibuka siapa saja.

1. Netlify Drop (paling mudah, lewat laptop)
   - Buka app.netlify.com/drop
   - Ekstrak zip ini, lalu seret folder hasilnya ke halaman itu.

2. GitHub Pages (bisa lewat HP)
   - Buat repositori baru di github.com, unggah semua file lewat "Add file > Upload files".
   - Settings > Pages > pilih branch main > Save.

3. Cloudflare Pages
   - pages.cloudflare.com > Create project > Direct Upload.

Setelah online, buka linknya di Chrome HP lalu pilih "Pasang aplikasi" / "Tambahkan ke layar utama". Ikon biru Lembarku akan muncul dan aplikasi bisa dibuka tanpa bilah browser.
